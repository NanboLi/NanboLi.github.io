A world model needs to remember several evolving entities and their interactions. FACTS replaces a single undifferentiated recurrent state with a factored, graph-structured memory, bringing structured representations together with efficient state-space sequence modelling.

## Routing, structure, and propagation

A routing mechanism learns permutable memory representations so that the model can handle changes in input ordering. Selective state-space propagation updates these representations over time, while the graph structure supports relationships between factors. The framework also supports parallel computation for high-dimensional sequences.

The paper evaluates this approach on multivariate time-series forecasting, object-centric world modelling, and spatial-temporal graph prediction, exploring how a shared structured-memory framework applies across these settings.
